[p62] 1970: MYCIN K-NEAREST NEIGHBORS - KNN Algoritmo que se baseia na proximidade entre os dados para realizar previsões ou classificações. Armazena os dados de treinamento e, ao receber novos dados, calcula a distância entre este e os demais ponto do conjunto. A classe ou valor do novo dado é determinado com base nos k vizinhos mais próximos!

[p86] 1970: MYCIN K-NEAREST NEIGHBORS - KNN Qual o papel do valor k? Overfitting! O modelo olha para pouquíssimos vizinhos. Isso torna k pequeno: a classificação muito sensível a ruídos ou outliers. Por exemplo, k=1: Novo ponto assume a classe do vizinho mais próximo. Vantagem: captura detalhes locais. Porém, um ponto rotulado errado pode alterar tudo!
[p89] 1970: MYCIN K-NEAREST NEIGHBORS - KNN Qual o papel do valor k? O modelo considera muitos vizinhos, até mesmo todos os pontos. Ignora detalhes locais! Mas k grande: pode ser mais robusto. Underfitting! Por exemplo, k=100: Se eu tiver uma base de dados com 100 amostras, o KNN vai considerar todos os pontos. A classificação será a classe majoritária do dataset.
[p90] 1970: MYCIN K-NEAREST NEIGHBORS - KNN Qual o papel do valor k? → Modelo muito flexível → Overfitting K muito grande → Modelo excessivamente simples → Underfitting K pequeno

[p95] LIMITAÇÕES KNN Na versão mais básica do algoritmo, a classe de cada vizinho possui o mesmo peso: 1 voto por vizinho mais próximo! Isso torna o algoritmo sensível à escolha de k Existe uma versão alternativa para reduzir a sensibilidade e permitir o aumento de k (aumentando a robustez a ruído): Ponderar cada voto pela respectiva distância.
[p96] LIMITAÇÕES KNN kNN → Classificador Lazy Não constrói um modelo: para classificar novas instâncias é necessário calcular as distâncias entre todas as instâncias do treinamento! Classificar novas instâncias é custoso computacionalmente! Existem alternativas para solucionar isso: KD-Tree

[p101] RESUMO KNN Vantagens: Simples, intuitivo, muito fácil de implementar e sem treinamento complexo! Pode ter um poder de classificação elevado a depender dos dados de treino. Limitações: Sensível a ruído (especialmente com k pequeno), sensível às escalas, sensível a escolha do k, sensível a atributos irrelevantes, lento para bases grandes e sofre com muitas dimensões..
